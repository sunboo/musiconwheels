4.3 Smooth Voice Leading

Good chord changes move each voice as little as possible, like singers stepping to the nearest note.

▶ Open it on the circle

Why it works

Played in root position every time, all the voices jump together and make parallel fifths and octaves, which classical teachers avoid. Choosing the nearest inversion keeps shared notes still and moves the rest by step.

Compare

  • Root-Position Jumps: Every chord in root position: the whole hand jumps each time.
  • Smooth Voice Leading: Each chord picks the inversion nearest the last one: shared notes stay put.

Try it

Flip between "Root-Position Jumps" and "Smooth Voice Leading". Same chords, very different motion in the piano.
